# Glosario operativo

| Concepto | Significado y ejemplo |
|---|---|
| Granularidad | Qué representa una fila: línea de pedido, pedido, cliente/mes. |
| Clave primaria | Identifica una fila sin ambigüedad; item_id o linea_id. |
| Clave foránea | Relaciona una fila con catálogo/cabecera; producto_id. |
| Cardinalidad | Cantidad de coincidencias esperadas: muchos ítems a un producto. |
| NULL / None / NaN | Ausencia o desconocimiento; no automáticamente cero. |
| Métrica / KPI | Medición / medición elegida para un objetivo y decisión. |
| Numerador / denominador | Lo medido / población o base de comparación coherente. |
| Drop | Entrega a un cliente; su tamaño puede medirse en Bs o unidades. |
| Ticket | Importe por documento; definir factura, pedido o entrega. |
| Recencia | Días desde última compra hasta una fecha de corte explícita. |
| Frecuencia | Compras por cliente/periodo o intervalos, según definición. |
| ABC | Clasificación por una variable y umbrales declarados. |
| Pareto | Concentración de aportes; 80/20 no es obligatorio. |
| Mediana / percentil | Valor central / umbral de posición según convención. |
| IQR | Q3−Q1, dispersión del 50% central. |
| Desviación / error estándar | Variación de observaciones / incertidumbre del estimador. |
| P-valor | Probabilidad de un resultado al menos tan extremo bajo H0 y el modelo. |
| Correlación / causalidad | Asociación / efecto atribuible a una intervención bajo diseño adecuado. |
| ETL / ELT | Transformar antes / después de cargar al destino. |
| Bronze / Silver / Gold | Entrada preservada / datos validados / producto analítico. |
| Rechazo | Fila excluida con motivo registrado y trazabilidad. |
| Idempotencia | Repetir la carga no multiplica datos ni cambia los resultados lógicos. |
| Hecho / dimensión | Evento medible / descripción de sus claves. |
| Contexto de filtro | Selección que determina el resultado de una medida DAX. |
| Cuadre | Conciliar conteos e importes con un camino independiente. |
| Logging | Registro de etapas, conteos y errores para reproducir decisiones. |
