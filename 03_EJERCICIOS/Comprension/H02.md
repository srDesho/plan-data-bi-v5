**1. Una función que rechaza.**

```python
def porcentaje_texto(texto):
    limpio = texto.strip().replace(",", ".")
    if not limpio.endswith("%"):
        raise ValueError("falta %: " + texto)
    n = float(limpio[:-1])
    if n < 0 or n > 100:
        raise ValueError("fuera de rango: " + texto)
    return n / 100

for t in ["15%", " 7,5% ", "120%", "abc"]:
    try:
        print(porcentaje_texto(t))
    except ValueError as e:
        print("error:", e)
```
