**1. Contexto de filtro con números.**

```python
# Ruta | Mes | Ventas | Meta
filas = [("R01", "Ago", 1000, 1200), ("R01", "Sep", 1500, 1200), ("R02", "Ago", 800, 1000), ("R02", "Sep", 900, 1000)]
def medida(filtro):
    sel = [f for f in filas if filtro(f)]
    v = sum(f[2] for f in sel)
    m = sum(f[3] for f in sel)
    return v, m, round(v / m, 4)
print(medida(lambda f: f[0] == "R02"))
print(medida(lambda f: f[0] == "R02" and f[1] == "Sep"))
print(medida(lambda f: True))
```
