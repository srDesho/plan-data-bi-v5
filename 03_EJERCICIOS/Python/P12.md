# P12 · recencia

Nivel 2/3 · Tiempo objetivo 20 min · Primera vez: 30–55 min.

## Situación

Para medir inactividad se calcula cuántos días pasaron desde la última compra hasta una fecha de corte fija.

## Qué recibe y qué devuelve

- **Recibe:** `ultima` y `corte`: fechas en formato `AAAA-MM-DD` (texto).
- **Devuelve:** Un entero: los días entre `ultima` y `corte`.

## Reglas

- Si `ultima` es igual a `corte`, el resultado es 0.
- Si `ultima` es posterior a `corte`, lanza `ValueError`.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `recencia('2026-09-01', '2026-09-30')` → `29`
- `recencia('2026-09-30', '2026-09-30')` → `0`
- `recencia('2026-10-01', '2026-09-30')` → lanza `ValueError`
