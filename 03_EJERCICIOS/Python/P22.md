## Situación

Una exportación puede repetir filas idénticas. Se eliminan solo las que son idénticas en TODAS las columnas; si una clave se repite con datos distintos, eso es un conflicto y no se toca.

## Qué recibe y qué devuelve

- **Recibe:** `df`: DataFrame.
- **Devuelve:** Un DataFrame nuevo sin filas idénticas repetidas, con el índice reiniciado (0, 1, 2…).

## Reglas

- Se conserva la primera aparición de cada fila.
- Dos filas con la misma clave pero otro monto NO son duplicados exactos.
- No modifica `df`.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `quitar_exactos(pd.DataFrame({'id': [1, 1, 1], 'monto': [10, 10, 25]}))` → dos filas (1, 10) y (1, 25)

## Pistas (en este orden, solo cuando las necesites)

1. **Orientación.** «Idéntica» significa igual en todas las columnas.
2. **Concepto Python.** `drop_duplicates()` sin argumentos compara filas completas; `reset_index(drop=True)` reinicia el índice (lección 9.5).
