Nivel 2/3 · Tiempo objetivo 20 min · Primera vez: 25–45 min.
Lee las lecciones 7.6 y 8.4 (`02_TEORIA/07_Python_basico.md` y `02_TEORIA/08_Python_funciones_archivos.md`). Escribe `def filtrar_fecha(filas, inicio, fin):` en `mi_trabajo/python/mis_funciones.py` (parte desde `03_EJERCICIOS/Python/plantilla.py`).

## Situación

Para trabajar con un periodo necesitas quedarte con las filas cuya fecha cae dentro del rango.

## Qué recibe y qué devuelve

- **Recibe:** `filas`: lista de diccionarios con la clave `'fecha'` en formato `AAAA-MM-DD`; `inicio` y `fin`: fechas del mismo formato.
- **Devuelve:** Una lista nueva con las filas cuya fecha está entre `inicio` y `fin`, ambos incluidos, en el orden original.

## Reglas

- Ambos extremos están incluidos.
- No modifica la lista de entrada.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `filtrar_fecha([{'fecha': '2026-09-09'}, {'fecha': '2026-09-10'}, {'fecha': '2026-09-12'}, {'fecha': '2026-09-13'}], '2026-09-10', '2026-09-12')` → `[{'fecha': '2026-09-10'}, {'fecha': '2026-09-12'}]`

## Pistas (en este orden, solo cuando las necesites)

1. **Orientación.** Es un filtro: recorres y te quedas con lo que cumple.
2. **Concepto Python.** Las fechas ISO se comparan correctamente como texto; una comparación encadenada `inicio <= x <= fin` expresa el rango (lecciones 7.6 y 8.4).
3. **Si no cuadra.** Prueba con una fecha igual a `inicio` y otra igual a `fin`: ambas deben quedar.
