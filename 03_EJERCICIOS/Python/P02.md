# P02 · porcentaje

Nivel 1/3 · Tiempo objetivo 10 min · Primera vez: 15–30 min.
Lee las lecciones 7.3 y 7.6 de `02_TEORIA/07_Python_basico.md`. Escribe `def porcentaje(real, meta):` en `mi_trabajo/python/mis_funciones.py` (parte desde `03_EJERCICIOS/Python/plantilla.py`).

## Situación

Ventas reporta cumplimiento: lo vendido frente a la meta. Una meta de cero o negativa no permite calcular un porcentaje.

## Qué recibe y qué devuelve

- **Recibe:** `real` y `meta`: números.
- **Devuelve:** `100 × real / meta`; o `None` si la meta es cero o negativa.

## Reglas

- `None` significa «no calculable»; no devuelvas 0 ni lances un error.
- No imprimas: usa `return`.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `porcentaje(45, 60)` → `75.0`
- `porcentaje(10, 0)` → `None`
- `porcentaje(5, -3)` → `None`

## Pistas (en este orden, solo cuando las necesites)

1. **Orientación.** Piensa primero qué casos tiene el problema: meta válida y meta que no permite dividir.
2. **Concepto Python.** Un `if` decide entre dos caminos; antes de dividir, comprueba la condición que impediría hacerlo (lección 7.3 «Tipos de datos y aritmética», sobre dividir entre cero; lección 7.6 «Booleanos, comparaciones y None», `None` como «no calculable»; el `if` completo está en 7.10).
3. **Si no cuadra.** Prueba con meta 0: si ves `ZeroDivisionError`, dividiste antes de comprobar.
