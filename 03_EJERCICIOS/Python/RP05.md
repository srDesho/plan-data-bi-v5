## Situación

El inventario llega a veces con filas dañadas: un número escrito como texto, un campo vacío, un stock negativo o una fila con columnas de menos. No debes perder esas filas en silencio: se separan con su motivo para poder reportarlas.

## Qué recibe y qué devuelve

- **Recibe:** `ruta`: ruta (texto o `Path`) de un CSV UTF-8 con la cabecera `producto_id,stock_inicial,stock_final,salidas_unidades`.
- **Devuelve:** Una tupla `(validas, rechazadas)`. `validas` es una lista de diccionarios con las cuatro columnas como números enteros. `rechazadas` es una lista de tuplas `(numero_de_linea, motivo)`, donde `numero_de_linea` es la línea del archivo (la cabecera es la línea 1).

## Reglas

- Una fila es válida si tiene 4 campos, ninguno vacío, todos enteros y ninguno negativo.
- El motivo es uno de estos textos, evaluados en este orden: `'columnas incorrectas'`, `'campo vacío'`, `'no numérico'`, `'negativo'`.
- Las líneas completamente vacías se ignoran (no son válidas ni rechazadas). El archivo puede empezar con BOM.
- Usa el módulo `csv` y `try/except ValueError`; no uses pandas. No detengas el programa por una fila dañada.
- Debe cuadrar: filas válidas + rechazadas = filas de datos con contenido.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- Si el archivo es `04_DATASETS/inventario.csv` (40 filas), `leer_inventario(ruta)` devuelve 40 válidas y `[]` rechazadas.
- Si agregas al final de una copia las líneas `41,abc,100,5`, `42,,100,5`, `43,50,-3,5` y `44,10,20`, las rechazadas son `[(42, 'no numérico'), (43, 'campo vacío'), (44, 'negativo'), (45, 'columnas incorrectas')]`.
