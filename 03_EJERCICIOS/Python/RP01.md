Nivel 1/3 · Tiempo objetivo 10 min · Primera vez: 15–25 min.

## Situación

Ventas aplica descuentos en porcentaje sobre el precio de lista y necesita el precio final, con dos decimales, para el catálogo.

## Qué recibe y qué devuelve

- **Recibe:** `precio`: número mayor o igual que 0; `porcentaje`: número.
- **Devuelve:** El precio final con 2 decimales, o `None` si `porcentaje` no está entre 0 y 100 (ambos incluidos).

## Reglas

- No imprimas: usa `return`.
- Un descuento de 100 % deja el precio en 0.0.
- Redondea solo el resultado final.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `con_descuento(100, 10)` → `90.0`
- `con_descuento(50, 150)` → `None`
