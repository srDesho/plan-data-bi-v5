# P30 · auditoria_conteos

Nivel 3/3 · Tiempo objetivo 20 min · Primera vez: 30–55 min.
Lee `02_TEORIA/05_calidad_ETL.md`. Escribe `def auditoria_conteos(bronze, duplicados, rechazos, silver):` en `mi_trabajo/python/mis_funciones.py` (parte desde `03_EJERCICIOS/Python/plantilla.py`).

## Situación

La ecuación de control de un ETL: las filas que entraron deben explicarse como duplicados eliminados, filas rechazadas y filas que pasan a Silver.

## Qué recibe y qué devuelve

- **Recibe:** Cuatro enteros: `bronze` (filas de origen), `duplicados`, `rechazos` y `silver`.
- **Devuelve:** `True` si `bronze = duplicados + rechazos + silver`.

## Reglas

- Si algún conteo es negativo, lanza `ValueError`.
- Si la ecuación no se cumple, lanza `ValueError` con un mensaje que muestre los números.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `auditoria_conteos(100, 5, 3, 92)` → `True`
- `auditoria_conteos(100, 5, 3, 91)` → lanza `ValueError`
- `auditoria_conteos(10, -1, 1, 10)` → lanza `ValueError`
