## Situación

La versión Pandas de G5: cuántos clientes tiene cada ruta.

## Qué recibe y qué devuelve

- **Recibe:** `clientes`: DataFrame con las columnas `cliente_id` y `ruta`.
- **Devuelve:** Un DataFrame con las columnas `ruta` y `clientes`, ordenado por `ruta` ascendente y con índice 0, 1, 2…

## Reglas

- `clientes` es la cantidad de filas de cada ruta.
- No modifica el DataFrame de entrada.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `contar_por_ruta(pd.DataFrame({'cliente_id': [1, 2, 3, 4], 'ruta': ['R02', 'R01', 'R01', 'R01']}))` → R01 → 3, R02 → 1
