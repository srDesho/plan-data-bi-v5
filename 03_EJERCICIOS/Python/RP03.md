## Situación

Compras quiere saber cuántas unidades se movieron por categoría a partir de una lista de líneas, sin usar una hoja de cálculo.

## Qué recibe y qué devuelve

- **Recibe:** `lineas`: lista de tuplas `(categoria, unidades)`.
- **Devuelve:** Un diccionario `{categoria: unidades_totales}`.

## Reglas

- Usa un bucle y un diccionario acumulador (sin `collections.Counter`).
- Lista vacía → diccionario vacío.
- No modifiques la lista recibida.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `unidades_por_categoria([('Snacks', 3), ('Bebidas', 5), ('Snacks', 2)])` → `{'Snacks': 5, 'Bebidas': 5}`
