## Situación

Operaciones quiere saber cuántos pedidos hay en cada estado a partir de una lista de estados.

## Qué recibe y qué devuelve

- **Recibe:** `estados`: lista de textos.
- **Devuelve:** Un diccionario `{estado: cantidad}`.

## Reglas

- Usa un bucle y un diccionario (sin `collections.Counter`): es el ejercicio para practicar el acumulador.
- Lista vacía → diccionario vacío.

## Ejemplos (para entender el formato; el corrector usa otros casos además de estos)

- `contar_estados(['anulado', 'anulado', 'entregado'])` → `{'anulado': 2, 'entregado': 1}`

1. **Orientación.** Recorre la lista una vez y lleva la cuenta de cada estado que encuentras.

3. **Si no cuadra.** Imprime el diccionario después de cada vuelta con una lista de tres estados; así ves cuándo la cuenta deja de crecer.
