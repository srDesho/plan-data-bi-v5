# C06 · ETL de transferencia completo

Nivel Integrador · 240 min. Teoría: `02_TEORIA/17_Transferencia_debug.md`.
Entrada: 04_DATASETS/transferencia/transacciones_raw.csv y catalogo.csv.

## Requerimiento

Recibe una exportación nueva. Construye contrato, perfilado, Bronze, Silver, rechazos, Gold cliente/mes y SQLite. Usa centavos enteros, valida catálogo y reejecución. Entrega README y resumen gerencial. Distribuye el trabajo en cuatro bloques de la semana 6: contrato 25 min el lunes, extracción 70 el martes, Silver 80 el miércoles y Gold/cuadre 65 el jueves (240 min en total).

## Entrega

- [ ] Resultado reproducible, cálculo/código propio y una interpretación para gerencia.
- [ ] Periodo, unidad observada, numerador y denominador declarados.
- [ ] Al menos un cuadre independiente y una limitación.
- [ ] README o nota que permita repetirlo; archivo propio sin datos privados en GitHub.

## Pistas y corrección

Pista 1: describe qué representa una fila y qué filtro pide gerencia.
Pista 2: separa agenda, pedido y venta entregada; comprueba claves y periodo antes de fórmulas.
Criterio específico: Ejecuta validar_final.py con --transferencia tras el intento y aplica rúbrica final.
Rúbrica general: exactitud 40%, validación 25%, explicación 25%, reproducción 10%; aprobar 70%.
Control separado: `08_SOLUCIONES/CASOS_RESPUESTAS.md`.
Para C06 aplica el corrector numérico y la rúbrica final. Excel/Power BI requieren evidencia manual real.
