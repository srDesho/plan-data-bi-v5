# C05 · Un pipeline funciona pero modifica datos

Nivel Intermedio · 45 min. Teoría: `02_TEORIA/10_Pandas_transformaciones.md`.
Entrada: Tabla pequeña que construirás a mano; referencia contratos P09/P11/P21.

## Requerimiento

Un parser convierte cantidades 3.7 a 3 y deja como 0 un precio ilegible. Diseña tres pruebas adversas, decide cuándo rechazar/detener y verifica que un catálogo con SKU duplicado no multiplique ventas.

## Entrega

- [ ] Resultado reproducible, cálculo/código propio y una interpretación para gerencia.
- [ ] Periodo, unidad observada, numerador y denominador declarados.
- [ ] Al menos un cuadre independiente y una limitación.
- [ ] README o nota que permita repetirlo; archivo propio sin datos privados en GitHub.

## Pistas y corrección

Pista 1: describe qué representa una fila y qué filtro pide gerencia.
Pista 2: separa agenda, pedido y venta entregada; comprueba claves y periodo antes de fórmulas.
Criterio específico: No truncar ni imputar precios; rechazos con causas; catálogo ambiguo detiene carga.
Rúbrica general: exactitud 40%, validación 25%, explicación 25%, reproducción 10%; aprobar 70%.
Control separado: `08_SOLUCIONES/CASOS_RESPUESTAS.md`.
